# Age-aware creative experience

Autween offers four broad presentation bands: 6–9, 10–12, 13–15 and 16–17. These are design presets, not assessments, developmental predictions, age verification or measures of ability.

Each band changes the tone, introduction, available creative formats and starting prompts. Younger experiences use concrete imaginative entry points and larger, symbol-forward controls. Teen experiences use independent formats such as field notes, editorial zines, narrative workshops and concept design, with a quieter visual language. The user can switch the preview band in the studio; the selection is not used to infer ability or support needs.

The studio offers symbol, word, and combined participation modes. Younger age-band previews start with symbols, while older previews start with words; participants can switch at any time. The starting idea can optionally be read aloud using the browser's local speech synthesis. Autween does not request microphone access or record audio. A quiet-presentation control is available, and each adaptation is visible and reversible.

Prompts are optional. Projects may remain unfinished. Users may change format or direction at any time. A blank project is a valid starting point. No timer, points, streaks, ranking or engagement score is used.

Drafts are stored in browser local storage only after an explicit Save action. When opened from a guardian-managed participant space, the storage key is scoped to that profile so sibling profiles do not share the same draft key. A public demo session is separate from guardian profile storage. Export creates a Markdown file only after an explicit action. No draft is uploaded or synchronized to an account. Clearing removes the current local draft.

This is a single-draft-per-participant prototype, not a complete multi-project library. Browser-local storage is not an encrypted vault and does not protect data from other people who can use the same device or browser account; do not store real child information. It has not been co-designed or usability-tested with autistic participants across these age bands. Age labels and prompts require review by autistic teens and adults, accessibility specialists and safeguarding advisors before real-world use. A guardian-managed profile does not establish age or legal guardianship by itself.
