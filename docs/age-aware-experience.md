# Age-aware creative experience

Autween offers four broad presentation bands: 6–9, 10–12, 13–15 and 16–17. These are design presets, not assessments, developmental predictions, age verification or measures of ability.

Each band changes the tone, introduction, available creative formats and starting prompts. Younger experiences use concrete imaginative entry points. Teen experiences use independent formats such as field notes, editorial zines, narrative workshops and concept design. The user can switch the preview band in the studio; the selection is not used to infer ability or support needs.

Prompts are optional. Projects may remain unfinished. Users may change format or direction at any time. A blank project is a valid starting point. No timer, points, streaks, ranking or engagement score is used.

The current /play/studio prototype stores one draft in browser local storage only after the user chooses Save. Export creates a Markdown file only after an explicit action. No draft is uploaded or synchronized to an account. Clearing removes the local draft.

This is a single-draft prototype, not a complete multi-project library. It has not been co-designed or usability-tested with autistic participants across these age bands. Age labels and prompts require review by autistic teens and adults, accessibility specialists and safeguarding advisors before real-world use. A guardian-managed profile does not establish age or legal guardianship by itself.
