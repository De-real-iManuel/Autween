# Autween prototype

This is a static, synthetic-data prototype. It has no backend, authentication, analytics, external AI API, or child accounts.

## Run it

Open `index.html` in a modern browser, or serve this folder using any static file server.

## Current interactions

- Select interests to filter activity cards.
- Disable personalization to view all activities.
- Toggle calm mode to reduce motion and visual saturation.
- Reset preferences.
- Generate a small fictional story from selected character/place options.

## Privacy boundary

Preferences exist only in the page's current memory. No information is sent to a server or persisted. Do not enter real children's personal information.

## Known limitations

- Activity recommendations are deterministic preference matching, not machine learning.
- “Explore” routes to the story studio placeholder; dedicated art, world-building, and cooperative activities are not implemented yet.
- The product is not ready for real child-to-child interaction and is not a clinical tool.
